# Feuille de route — 3 versions

## V1 — Le Studio IA (terminée)

**Objectif :** créer un produit digital complet et son marketing en une après-midi.

- [x] Fiche produit unique partagée par tous les modules
- [x] Ebook complet (sommaire, chapitres, points clés) + export PDF
- [x] Templates imprimables : planners, checklists, workbooks, trackers
- [x] Couverture IA + mockups 3D (livre, tablette, smartphone, pack) + visuels pub
- [x] Pages de vente (PAS, AIDA, storytelling) avec mockup intégré
- [x] Sites vitrines one-page responsives
- [x] Scripts vidéo UGC & storytelling + vidéo avec avatar IA (HeyGen)
- [x] Bibliothèque de projets (stockée dans le navigateur)

## V2 — Le SaaS commercialisable (en cours)

**Objectif :** transformer le studio en abonnement payant, multi-utilisateurs.

*Lot 1 (livré) : comptes, abonnements, crédits, cloud. Lot 2 : éditeur visuel, images IA, hébergement, variantes.*

- [x] Comptes utilisateurs (email, Google) et base de données
- [x] Abonnements Starter / Pro / Business : Stripe + Mobile Money
- [x] Crédits de génération par mois et suivi de la consommation
- [ ] Éditeur visuel : modifier textes, couleurs et images après génération
- [ ] Images générées par IA pour couvertures, sites et pages de vente
- [ ] Hébergement en 1 clic des sites et pages de vente (sous-domaine + domaine perso)
- [ ] 3 variantes par génération pour choisir la meilleure
- [x] Stockage cloud des projets, images et vidéos

## V3 — La machine de vente (plus tard)

**Objectif :** vendre, diffuser et optimiser automatiquement.

- [ ] Boutique intégrée + publication vers Chariow, Gumroad, Selar
- [ ] Vidéos UGC avancées : B-roll IA (Runway, Kling), plusieurs avatars, montage auto
- [ ] Programmation des publications TikTok, Instagram, Facebook
- [ ] Tests A/B des pages de vente et des hooks vidéo
- [ ] Statistiques : visites, conversions, ventes par produit
- [ ] Séquences emails et WhatsApp générées par IA
- [ ] Marketplace de templates entre créateurs + affiliation
- [ ] Mode agence : équipes, clients multiples, marque blanche, API

## Pourquoi cet ordre

1. **V1** prouve la valeur : un créateur sort un produit complet + son marketing sans compétence technique.
2. **V2** rend le produit vendable : comptes, abonnements, crédits, hébergement des pages.
3. **V3** augmente le revenu par client : vente, diffusion et optimisation automatiques.
